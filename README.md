# 电商零售数据清洗项目

## 项目简介
这是一个使用 Python 和 pandas 完成的电商零售数据清洗项目，通过一系列标准化的数据清洗步骤，对原始电商交易数据进行预处理，为后续数据分析与建模提供高质量、可靠的数据基础。

## 我完成的任务
- 读取原始数据文件
- 删除重复记录
- 删除 Customer ID 为空的记录
- 删除 Quantity ≤ 0 的无效记录
- 删除 Price ≤ 0 的无效记录
- 处理 InvoiceDate 字段为标准日期格式
- 导出清洗后的结果数据
- 生成并输出数据清洗统计信息（终端打印、TXT/JSON 文件）

## 实验思路
1. 首先搭建项目目录结构，自动创建输出文件夹，确保文件读写路径正确。
2. 将通过命令利用下载脚本获得的数据集转移到项目文件的data目录中，并读取 data 目录下的 CSV 原始数据，记录原始数据行数作为基准。
3. 在清洗前统计各类异常数据数量，包括重复值、空客户ID、无效数量与价格。
4. 按照业务规则依次执行数据清洗：去重、删除空客户ID、过滤无效数量与无效价格。
5. 将 InvoiceDate 字段转换为标准日期时间格式，便于后续时间维度分析。
6. 将清洗完成的数据保存到 output 目录，并生成清洗统计报告，以 TXT 和 JSON 格式输出。

## 运行方式
1. 创建并激活虚拟环境
2. 安装依赖（pandas）
3. 下载并准备数据，将 CSV 文件放入 data 目录
4. 运行程序
python main.py
